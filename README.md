# Очередь выгрузки — ТОП-10

Экран очереди машин на выгрузку: авто-обновление раз в 60 с, отметка «выгружен» одной кнопкой. Публикуется через GitHub Pages.

## Файлы

| Файл | Назначение | Бэкенд |
|------|-----------|--------|
| `index.html` | Очередь выгрузки — ТОП-10 (основная) | GAS `AKfycbzchor…` |
| `ocheredi.html` | Внутренняя очередь | GAS `AKfycbxfLB…` |

Одна кодовая база: страницы отличаются только `WEB_APP_URL`.

## Формат данных

- **GET** — JSON-массив: `[заголовки, ...строки]`. Строка: `[0]` время, `[1]` номер машины, `[3]` флаг «Да» (скрытые строки).
- **POST** `{"valueToHide": "…"}` (no-cors) — скрыть машину после выгрузки.

## Логика

- Строки с `[3] == 'Да'` скрыты, остальные сортируются по времени, показываются первые 10.
- Отметка «выгружен» требует подтверждения в модалке.
- При ошибке сети машина **остаётся в очереди** (раньше удалялась локально — баг).
